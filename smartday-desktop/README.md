# SmartDay 桌面端（Windows 壁纸日历）

Electron 桌面客户端：把日历“贴”在桌面上，托盘常驻、开机可见，与主应用数据实时同步。
复用网页端（../smartday-web）的完整业务与数据层，桌面端只负责窗口/托盘/系统集成。

## 卡片内操作方式

卡片右上角依次是 4 个按钮：**‹ 上个月** · **› 下个月** · **☰ 菜单** · **🔒/🔓 模式切换**（🔒 固定在最右端）。

> **‹ › ☰ 受 🔒 约束**（符合需求 8.4「桌面模式=日历只是背景，编辑模式才能切换月份/调设置」）：
> 锁定状态下 ‹ › ☰ 三个按钮变灰、不可点（点击直接穿透到桌面），本模式下**只有 🔒 本身可点**；点 🔒 解锁后（🔓）它们才可用。
>
> **🔒 的点击语义**：单击即可切换模式；**双击也不会自我抵消**（500ms 内的重复点击会被合并），
> 因此「双击进入编辑」的老习惯同样有效。锁定态还给 🔒 额外留了 16px 命中范围，避免差几像素点空。
>
> 点 ☰ 展开的菜单包含：

| 菜单项 | 说明 |
|--------|------|
| 🎨 配色主题 | 晨雾蓝 / 深邃夜 / 暖阳沙 / 薄荷绿（带色块预览） |
| 🧊 材质 | 毛玻璃（透出壁纸）/ 实色 |
| 🫥 背景透明度 | **0-100 连续滑块** |
| 👁 显示内容 | 节假日·节气 / 农历 / 任务 / 日记标记 / 今日面板，逐个开关 |
| 其它 | 打开主应用 / 刷新 / **隐藏桌面日历**（托盘菜单可重新显示） |

> 位置与大小不再放进菜单：直接**拖动标题栏移动**、**拖动窗口边缘或右下角 ◢ 缩放**即可（托盘里保留了「窗口复位」作为兜底）。

## 日期单元格显示规则

- **只显示本月日期**：前后月不再显示数字，只留空占位；行数按本月实际周数自适应（5 或 6 行）；
- **阳历 / 农历 / 节日同一行**：如「3 廿二 国庆节」，空间不足时节日自动截断（只显示前几个字）；
- **农历简称规则**：农历**初一显示月份**（如「九月」「闰六月」），其余日期**只显示日名**（如「廿一」「三十」）；
- **星期表头只占一行文字高度**：不再和日期格一样高，日期格因此能分到更多空间；

- **调休「班」/ 放假「休」角标**：周末或节假日调休上班 → 橙色**班**；工作日放假 → 红色**休**（周末本身不标休）；
- **周六、周日两列单独着色**：单元格底色比平日更深一档（表头也标红），一眼看出周末。

## 四套配色主题（容器背景与单元格颜色明确区分）

| 主题 | 容器背景 | 单元格 | 文字 | 强调色 | 适用 |

| 深邃夜 ink | 深蓝黑 `rgba(20,29,48,.74)` | 玻璃白 8% | `#e6edf9` | `#60a5fa` | 深色壁纸、夜间护眼 |
| 暖阳沙 sand | 米杏 `rgba(247,234,216,.8)` | 暖白 `#fffdf7` | `#4a3728` | `#d97706` | 暖色/纸质质感壁纸 |
| 薄荷绿 mint | 薄荷 `rgba(222,244,235,.78)` | 纯白 `#ffffff` | `#14342b` | `#10b981` | 清新浅色壁纸 |

四种主题都遵循同一设计：**卡片头部为渐变色带**、**容器为浅/深底色**、**单元格为独立浅色块**，互不相同；
节日/节气、农历、事件条、今日面板都有各自的颜色层级，不再出现“整片白”的问题。

## 锁定/解锁的窗口层级行为

- **解锁（🔓）**：窗口置顶（`setAlwaysOnTop(true,'floating')`）并聚焦，方便拖动/缩放/设置；
- **锁定（🔒）**：取消置顶后 **显式 `moveTop()`**——否则 Windows 会把窗口直接压到最底层，
  表现为「一锁定日历就被刚才在它后面的窗口盖住、消失」。现在锁定后会留在原层级，
  既不会突然沉底，也不会永久置顶遮挡其它窗口；之后再点击别的窗口时它才会自然被盖住；
- 只有主动开启实验性的「保持置底」时，才会真正沉到桌面层（`HWND_BOTTOM`）。

## 两个关键实现说明（都是踩过的坑）

### 1. 为什么不用 `-webkit-app-region: drag` 拖窗口

系统拖拽区会把该区域内（含子元素）的鼠标点击交给窗口拖动处理，**编辑模式下点击 🔓 会被直接吞掉**，
表现为“解锁之后点不回去”。现在改为：渲染进程 pointerdown 通知开始，**主进程用 `screen.getCursorScreenPoint()`
每 16ms 读取真实光标位移驱动窗口移动/缩放**。点击事件不再被系统吞掉，拖动也更顺滑（快速拖出窗口也不会断）。

### 2. 点击穿透时如何保证小按钮可点

桌面模式使用 `setIgnoreMouseEvents(true, { forward: true })` 整窗穿透，早期依赖渲染进程 `mousemove` 放行，
**鼠标不动直接点击时收不到 mousemove，点击会被穿透**。现在由主进程每 60ms 轮询真实光标：
命中“可点击区域”（🔒 / ☰ / 任务勾选，含 8px 容差）才关闭穿透，离开后保留 400ms 宽限期恢复。

smartday-desktop/
├─ electron/

## 运行

```bash
# 1) 先构建网页端
cd smartday-web && npm install && npm run build

# 2) 桌面端
cd ../smartday-desktop && npm install
npm run make-icons     # 生成图标（首次）
npm start              # 生产模式启动

# 开发模式（两个终端）
cd smartday-web && npm run dev          # 终端 A：http://localhost:5173
cd smartday-desktop && npm run dev      # 终端 B
```

> 若环境存在 `ELECTRON_RUN_AS_NODE=1`（某些宿主注入），Electron 会退化成纯 Node 并报 `app is undefined`，需先清除：
> `Remove-Item Env:\ELECTRON_RUN_AS_NODE`。

## 已知边界

- **保持置底（实验）**：Win32 `SetWindowPos(HWND_BOTTOM)` 压到桌面层，部分系统/多屏可能被桌面图标遮挡，默认关闭。
- **真正的壁纸挂载**（成为壁纸本身）需把窗口父级挂到 `WorkerW`，属原生注入；本实现用“无边框透明 + 点击穿透 + 托盘常驻”等效方案。
- 多显示器：当前按主显示器工作区摆放。
