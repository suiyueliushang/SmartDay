# SmartDay 网页端（完整实现）

> 依据《SmartDay需求概述.md》从零生成的完整网页端（客户端）代码。
> 移动端代码按约定暂不生成；桌面壁纸日历以“网页预览页”形式交付（系统级能力留待 Electron/Tauri 封装）。

## 快速开始

```bash
cd smartday-web
npm install
npm run dev        # 开发（http://localhost:5173）
npm run build      # 生产构建（dist/）
npm run preview    # 预览构建产物
npx tsx scripts/smoke.ts   # 核心逻辑冒烟测试（农历/重复/ICS/Markdown）
```

## 技术栈

- **React 18 + Vite 5 + TypeScript**（严格模式）
- **zustand** 状态管理；**IndexedDB**（idb）本地持久化，离线优先、无需账号
- **marked + DOMPurify + highlight.js** Markdown 渲染与语法高亮
- 零路由依赖（内置 Hash 路由）、零 UI 框架（自带设计系统，亮/暗主题）

## 目录结构

```
smartday-web/
├─ src/
│  ├─ types/          领域模型（事件/任务/日记/专注/设置…）
│  ├─ db/             IndexedDB 仓储层
│  ├─ store/          全局状态（数据 + UI）
│  ├─ lib/            日期/农历节假日/Markdown/重复规则/提醒引擎/导入导出/云同步客户端
│  ├─ components/     通用组件、日历视图、任务详情右侧抽屉、Markdown 编辑器、专注计时器、通知中心、搜索
│  ├─ pages/          概览/日历/任务/笔记/专注/设置/桌面日历
│  ├─ hooks/          useNow
│  ├─ app/            应用引导（主题、提醒循环、每日重置、自动同步）
│  ├─ App.tsx         应用外壳与路由
│  └─ index.css       设计系统（亮/暗主题）
└─ scripts/smoke.ts   核心逻辑冒烟测试
```
